# Онлайн-кинотеатр

Django-проект: выбор фильмов по жанру с сохранением настроек в cookies.

## Возможности

- Выбор фильмов по жанру (боевик, комедия, драма, ужасы, фантастика)
- Переключение темы (светлая/тёмная)
- Переключение языка (русский/английский)
- Сохранение последних посещённых страниц
- Все настройки сохраняются в cookies
